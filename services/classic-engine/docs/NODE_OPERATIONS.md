# 运行与恢复

- 在线状态以新鲜心跳和中心连接为准，进程存在不代表可接单。
- 停止先停止领取，再排空计算与交付；保留未知结果和未确认回执。
- 普通结果以 SQLite 原子保存描述和字节，终态回执后清除。断网重传原结果，不重新计算。
- 文件工作目录持久化；只在中心明确终态/撤销且本地无活动操作后回收，缺项不代表可删除。
- 升级先核对协议与检查点兼容性；不兼容时排空任务，不能清数据库强行启动。
- 节点身份不得在两台机器同时使用；新部署申请独立身份。
- 日志保留阶段、错误码和数值耗时，不记录图片、识别全文、令牌或签名地址。

配置见[节点配置](../../../docs/NODE_CONFIGURATION.md)，部署入口见[仓库 README](../../../README.md)。
